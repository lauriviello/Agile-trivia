# Agile-trivia

Here's the fully upgraded live multiplayer mode! 🎉 Here's how it works:
📺 For the Facilitator (Host):

Open this artifact and click "Host a Game"
A 4-digit game code appears — share it with participants
Watch players join in real time on the lobby screen
Hit Start Game when everyone's in
The host screen shows questions, a live response counter, and a 20-second timer — the answer reveals automatically when everyone responds or time runs out

📱 For Participants (Players):

Open this same artifact on their phone/laptop
Click "Join a Game", enter the code + their name
Questions appear on their device — tap to answer
After each question they see the explanation and live leaderboard

✨ What's synced in real time:

Players joining the lobby
Questions appearing simultaneously on all devices
Response count updating live on the host screen
Auto-reveal when everyone has answered (or timer runs out)
Scores, leaderboard, and explanations after each answer
Final results across all devices

💡 Pro tip for your induction session: Host on a laptop projected on screen, have participants open it on their phones — works just like Slido or Kahoot!
